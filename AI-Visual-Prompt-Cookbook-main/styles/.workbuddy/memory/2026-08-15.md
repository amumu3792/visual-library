## 修复：本地同步.bat "出错" 实为收藏卡片图裂
- 用户新增收藏 "High-End Skincare Product Poster"，图用 Obsidian `![[https://...s3...X-Amz-Expires=300...]]` 写法（5 分钟过期临时 S3 链接）。
- 根因：`kb_core.parse_user_additions()` 把 `![[...]]` 内所有内容当本地文件名，拼成 `视觉资料库/用户补充/图片/https://...` 坏路径 → 卡片图裂。bat 本身没崩，用户误判为"同步出错"。
- 修复（kb_core.py）：
  1. import 加 `urllib.request`；
  2. 新增 `_download_user_image(url)`：下载远程图到 `视觉资料库/用户补充/图片/remote_<md5>.png`，存在性去重、超时 25s、失败回退远程 URL；
  3. `![[url]]` 与 `![](url)` 分支改为先尝试下载本地，成功则 kind=local、src 指向本地相对路径，失败回退远程 URL。
- 验证：同步后该卡片 src 已指向本地 `remote_6d3ef8ef5b5d.png`（1.24MB 实图）；HTML 体检 0 base64、0 坏路径、135 项、385KB。
- 已更新 MEMORY.md（用户补充图片处理规则 + 现状）。
- 后续：用户再粘 Obsidian 图链接，双击同步本地.bat 即自动存本地、永不过期；若同步时链接已过期需重粘有效链接。
