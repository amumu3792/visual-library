## 新增：带登录的后端管理器（自助删除/改名单条收藏）
- 用户诉求：之前"点同步重写整库"已扼杀；但用户想要一个能登录的后端，以后类似"标题错了/想删某条"的问题自己在前端登录、点删除解决，不用找 AI、不碰 py。且删除必须是"针对某一条改源文件再重生整页"（非盲目全量重写）。
- 实现（单一真相源仍为 `kb_core.py`）：
  - `kb_core.py` 新增 `remove_user_entry(title)` / `rename_user_entry(old,new)`：只改 `用户补充.md` 里对应的 `##` 块，改前备份 `.bak`，改完调 `write_merged_html()`+`write_table_html()` 重生两页。**绝不删图片、绝不盲改全库**。
  - `design-knowledge-base.html` 模板（`HTML_TMPL`）注入：页头「🔧 管理登录」按钮 + 登录弹窗（密码）+ 登录后每条「我的收藏」卡片左上角 🗑 删除 / ✎ 改名 按钮 + JS（API 用 `location.origin`，`file://` 打开时提示用管理器）。
  - `kb-manager.py`（端口 8137）：静态托管 + `POST /api/login`（密码默认 `kb2026`）→ token；`DELETE /api/entries/<标题>`、`POST /api/entries/<标题>/rename` 需 Bearer token；`GET /api/entries` 列表。token 存内存，重启失效。
  - `启动管理器.bat`：双击启动 `kb-manager.py` 并开浏览器 `http://127.0.0.1:8137/design-knowledge-base.html`。
- 实测（已通过后清理）：登录→删除"一直圆珠笔的海报"成功（134→133）；md 该条消失、`.bak` 生成、224 图未删、268 本地图 0 缺失、表格页同步刷新、无重复提示词。测试完已从 `.bak` 恢复该条（134 项），让用户自己用管理器体验删除/改名。
- 注意：manager 的删除只针对"我的收藏"（用户补充.md），风格库/GPT 模板来自上游/生成，不在管理器删除范围内（避免误删上游内容）。
