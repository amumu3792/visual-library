### 01. 博物馆图鉴式拆解信息图

**适用场景：** 汉服、凤冠、盔甲、器物、古籍、兵器等任何主题的结构拆解展板。国家博物馆展板级质感，结构拆解、中文标注、材质说明、纹样寓意、色彩含义一应俱全。

**效果展示：**

![图像](https://pbs.twimg.com/media/HGb9amTaQAAGFEJ?format=jpg&name=large)

**提示词模板：**

```text
请根据【主题】自动生成一张"博物馆图鉴式中文拆解信息图"。

要求整张图兼具真实写实主视觉、结构拆解、中文标注、材质说明、纹样寓意、色彩含义和核心特征总结。你需要根据【主题】自动判断最合适的主体对象、服饰体系、器物结构、时代风格、关键部件、材质工艺、颜色方案与版式结构，用户无需再提供其他信息。

整体风格应为：国家博物馆展板、历史服饰图鉴、文博专题信息图，而不是普通海报、古风写真、电商详情页或动漫插画。背景采用米白、绢纸白、浅茶色等纸张质感，整体高级、克制、专业、可收藏。

版式固定为：
- 顶部：中文主标题 + 副标题 + 导语
- 左侧：结构拆解区，中文引线标注关键部件，并配局部特写
- 右上：材质 / 工艺 / 质感区，展示真实纹理小样并附说明
- 右中：纹样 / 色彩 / 寓意区，展示主色板、纹样样本和文化解释
- 底部：穿着顺序 / 构成流程图 + 核心特征总结

若主题适合人物展示，则以真实人物全身站姿为中央主体；若更适合器物或单体结构，则改为中心主体拆解图，但整体仍保持完整中文信息图形式。所有文字必须为简体中文，清晰、规整、可读，不要乱码、错字、英文或拼音。重点突出真实结构、材质差异、文化说明与图鉴气质。

避免：海报感、影楼感、电商感、动漫感、cosplay感、乱标注、错结构、糊字、假材质、过度装饰。
```

**使用要点：** 把【主题】换成任意文物/服饰/器物名称即可。通用模板，无需提供其他信息，AI 会自动判断结构。

### 04. 科普百科图

**适用场景：** 大熊猫、孔雀等动物，植物、历史人物、科学知识等。竖版科普百科卡，模块化排版，图鉴感、百科感拉满。

**效果展示：**

![图像](https://pbs.twimg.com/media/HGcAZlsa8AEpG1O?format=jpg&name=large)

![图像](https://pbs.twimg.com/media/HGcAZj5aoAAnBtd?format=jpg&name=large)

![图像](https://pbs.twimg.com/media/HGcAZj6bYAAitbp?format=jpg&name=large)

**提示词模板：**

```text
请根据【主题】生成一张高质量竖版「科普百科图」。

这张图不是普通海报，也不是单纯插画，而是一张兼具"图鉴感、百科感、信息结构感、收藏感"的模块化科普信息图。整体风格参考高级博物图鉴、现代百科书页、生活方式知识卡和社交媒体高传播信息图的结合。

请让画面包含：
- 一个清晰漂亮的主题主视觉
- 若干局部特征放大细节
- 多个圆角模块化信息分区
- 清楚的标题层级与重点标签
- 简洁但丰富的百科内容
- 可视化评分、要点总结或Top 5模块

内容栏目请根据主题自动适配，优先从这些方向中选择并合理组合：
基础档案、分类信息、外观特征、习性/生态、形成机制/结构组成、生长或使用条件、养护或维护建议、风险与注意事项、适合人群或适用场景、优缺点对比、快速评分卡。

视觉要求：
浅色干净背景，柔和配色，轻阴影，精致小图标，圆角信息框，整洁排版，信息密度高但不拥挤，阅读体验好。整体必须像真正可以发布、阅读、收藏、系列化生产的科普百科卡，而不是广告图。

请不要做成普通商业宣传海报。要突出"知识整理 + 模块信息 + 图鉴式展示"的特征。
```

**使用要点：** 把【主题】换成任意动物/植物/科学知识。AI 自动适配内容栏目。

**适用场景：** 胸肌、腹肌、引体向上等肌群或动作的训练计划。自动输出热身、主训动作、进阶路径、替代动作、恢复建议等完整训练卡。

![[Pasted image 20260809151922.png]]

![[Pasted image 20260809151922.png]]

**提示词模板：**

```text
请生成一张中文健身信息图，主题为：【xxx】。

要求这张图既专业又实用，适合普通成年人作为训练参考。默认对象为无严重伤病的健康成年人；如果没有额外说明，默认训练目标为"增肌 + 基础力量提升"，默认训练水平为"新手到中级之间"，默认训练场景为"普通健身房"，默认单次训练时长控制在 40–60 分钟内。

请根据【训练主题】自动判断输出类型：

1）如果【训练主题】是某个肌群或身体部位（例如：胸肌、背阔肌、肱二头肌、腹肌、肩部、腿部等），请输出一张"该部位训练计划信息图"。
2）如果【训练主题】是某个动作或技能目标（例如：引体向上、俯卧撑、双杠臂屈伸、深蹲等），请输出一张"动作解锁 / 进阶训练计划信息图"。

整张图请采用清晰、现代、专业、易读的中文信息图风格，竖版排版，视觉简洁，重点突出，适合社交媒体分享或训练参考卡片。不要写成长篇大论，每个模块用简洁短句呈现，数字信息要醒目。

这张信息图必须包含以下内容：
【A. 标题区】主标题 + 副标题
【B. 训练目标区】
【C. 热身区】
【D. 主训练区】（核心部分，4–6个动作）
【E. 进阶 / 解锁逻辑区】
【F. 替代动作区】
【G. 执行提醒区】
【H. 恢复建议区】
【I. 视觉设计要求】现代、清爽、专业、模块化卡片布局

请最终输出为"一张完整的信息图内容"，而不是只给普通段落文字。
```

**使用要点：** 输入肌群名或动作名即可。AI 自动判断输出类型（部位训练计划 vs 动作解锁进阶）。

**适用场景：** 鬼灭之刃、火影忍者、死神、龙珠等动漫/小说/历史人物关系。颜色、线条、层级一图呈现，核心人物突出、关系类型一目了然。

![[Pasted image 20260809152941.png]]

![[Pasted image 20260809152949.png]]

**提示词模板：**

```text
请根据【主题】，生成一张高设计感的人物关系图海报。要求这张图不是普通插画，而是兼具信息可视化、叙事结构、海报设计感和作品风格还原度的人物关系图。

请自动完成以下内容：
- 识别该主题对应的作品及其核心设定
- 提取最具代表性的 6–12 位关键人物，必要时不超过 15 位
- 识别并展示关键人物关系，包括血缘、爱情、友情、联盟、敌对、师徒、主从、操控、背叛、秘密关系等
- 自动按作品特点选择合适的构图方式，如主角中心型、双核心对峙型、阵营分区型、家族谱系型或时间演变型
- 自动提炼作品的风格DNA，包括色彩、世界观符号、材质纹理、情绪氛围、排版语言和代表性元素
- 将这些风格元素转化为人物关系图的整体视觉设计，而不是简单复制某张官方海报
- 用不同颜色、线型、箭头区分不同关系，保证线条清晰、层次分明、不杂乱
- 核心人物最突出，重要人物次之，次级人物弱化，形成明确视觉层级
- 每个人物名称清晰可读，必要时可加入身份或阵营标签

最终成品应满足：
- 一眼看懂人物主次和关键关系
- 具有明显的原作品气质与设定感
- 兼具信息图的清晰度与海报的高级设计感
- 画面统一、精致、完整、适合社交媒体传播或海报展示
- 避免廉价流程图感、避免杂乱堆砌、避免信息过载
```

**使用要点：** 输入作品名即可。如需不同风格，可新开会话或写简短提示词"帮我生成xxxx的人物关系图"。

```text
主题：【主题，例如昆虫研究所 / 未来生存基地 / 魔法药剂工坊 / AI自动化公司 / 植物工厂 / 儿童学习中心 / 太空补给站】
空间名称 / 品牌名：【品牌名或空间名称，可为空】
世界观方向：【现实 / 科幻 / 童话 / 魔法 / 末日 / 博物馆 / 实验室 / 经营模拟 / 校园 / 自然生态】
建筑类型：【小屋 / 基地 / 工厂 / 实验室 / 商店 / 博物馆 / 地下空间 / 飞船 / 多层工作室】
核心功能：【这个空间主要用来做什么，例如研究、生产、展示、生活、训练、交易、学习、维修、种植】
主色调：【主色调，例如浅蓝、薄荷绿、奶油黄、粉色、橙绿、紫蓝、白蓝科技色】
辅助色：【辅助色，可为空】
点缀色：【点缀色，可为空】
画幅比例：【1:1 / 3:4 / 4:5 / 9:16】
信息密度：【中高密度 / 高密度 / 超高密度】
整体气质：【治愈、可爱、精密、童趣、科普、未来感、复古、清爽、探索感】

如果某些字段没有填写，请根据【主题】自动合理推导，不要让画面留空。所有内容都要围绕主题统一生成，避免加入无关元素。

【画面结构】
采用清晰的等距轴测视角 / isometric view / axonometric view，主体是一个被剖开的多层主题建筑或功能基地。观者可以同时看到建筑的正面、侧面、顶面和内部空间。整体建筑位于画面中心，占据画面主要面积，背景环境适度淡化，用来衬托主体。

建筑内部需要分成多个功能区域，每个区域都要有明确用途，而不是随机堆放装饰。可以包含：
1. 主工作区 / 核心操作区
2. 展示区 / 收藏区 / 标本区
3. 研究区 / 实验区 / 控制区
4. 储藏区 / 货架区 / 物资区
5. 生活区 / 休息区 / 小型居住区
6. 能源区 / 机器区 / 管道区
7. 种植区 / 培养区 / 生态区
8. 入口区 / 运输区 / 维修区
9. 楼梯、平台、走廊、栏杆、梯子等空间连接结构

各个区域之间要通过楼梯、走廊、平台、管道、桥架或电缆形成清晰的空间关系，让画面像一个真实可以运转的小型系统。

【道具与细节】
根据【主题】生成大量相关道具，并让它们分布在不同功能区中。道具需要具体、可识别、有主题关联，不能只是泛泛的装饰。每个小物件都应像游戏资产一样清晰可读，具有可点击、可互动、可收集的感觉。

道具类型可以包括：
- 主题设备：机器、仪器、工具、控制台、容器、屏幕、工作台
- 生活物件：桌椅、书架、床铺、杯子、箱子、柜子、灯具
- 展示物件：标本、模型、海报、说明牌、玻璃柜、陈列架
- 连接结构：管道、电线、梯子、楼梯、输送带、滑轨、平台
- 生态元素：植物、水箱、培养箱、土壤、树枝、岩石、标本
- 角色元素：少量小人物、小动物、机器人或主题生物，用来提供尺度感和故事感

道具数量要丰富，但要保持秩序。所有道具都应服务于空间功能和主题世界观。

【风格要求】
整体风格为清晰、可爱、精密的手绘卡通等距插画。线条干净，边缘略圆润，色彩明亮柔和，整体具有轻松、治愈、探索感。画面应有经营模拟游戏、儿童科普绘本、微缩模型、设定集页面的感觉。

避免过度写实，避免强烈暗黑光影，避免厚重油画感，避免复杂噪点。重点是清楚、精致、有层次、可读性强。

【颜色与光影】
使用高明度、低到中等饱和度的柔和配色。主色调统一，辅助色用于区分不同空间，点缀色用于突出关键设备和小道具。线稿颜色不要使用死黑，可使用深灰、蓝灰、棕灰等柔和描边。

光影保持轻量，不需要强烈真实投影。通过色块、结构、线条和局部高亮来建立层次。背景使用浅色、低对比度处理，使主体建筑更加突出。

【构图与阅读路径】
画面主体居中或略微偏上，建筑呈多层剖面结构。视觉阅读路径应从整体建筑轮廓开始，再进入各楼层功能区，最后观察细节道具。可以通过楼梯、平台、走廊、管线、轨道等元素引导视线。

整体画面要饱满但不拥挤，丰富但不混乱。每个房间、平台和角落都应该有内容，但仍然保持清晰的空间边界。

【背景环境】
背景可以根据主题加入弱化的外部环境，例如森林、城市、街道、地下岩层、实验园区、海底、太空、校园、工厂外墙等。背景不要抢主体，建议使用淡色、低透明度、低对比度处理，形成"主体清晰、背景退后"的效果。

【最终效果】
最终画面应像一张完整的主题空间设定图，既有建筑剖面图的结构感，又有游戏场景资产图的细节感，还带有微缩玩具屋的可爱探索感。它应该适合用于系列化视觉创作、IP世界观展示、游戏场景设定、品牌空间概念图、科普内容封面或小红书/Pinterest风格视觉发布。

请确保画面：
1. 等距轴测视角明确
2. 建筑剖面结构清楚
3. 多层功能区完整
4. 道具丰富且主题统一
5. 色彩柔和明亮
6. 线稿清晰干净
7. 背景弱化、主体突出
8. 信息密度高但不混乱
9. 具有可探索、可运营、可反复观察的微缩世界感
```

**使用要点：**

- 道具分 6 类：主题设备、生活物件、展示物件、连接结构、生态元素、角色元素
- 适合系列化发布
