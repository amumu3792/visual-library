工具脚本

sync-readme.py
从 GitHub README 抓取最新风格列表并重新生成 styles-overview.html / .csv。

更新风格总览表

当 GitHub 仓库新增风格后，在 视觉资料库 目录运行：
python sync-readme.py
需要把新增的图片/json 也下载到本地时加 --download：
python sync-readme.py --download
脚本会从 AI-Visual-Prompt-Cookbook-main/styles 读取本地数据，图片与 style.json 链接使用 file:// 绝对路径，双击 HTML 即可查看。
